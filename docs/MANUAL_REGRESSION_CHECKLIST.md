# 家谱网站人工回归检查表

每次修改后，在部署前按顺序检查。记录测试日期、版本、测试账号、族谱和结果；涉及写入的测试请使用明确标记的测试数据，完成后按正常页面流程清理。

| 序号 | 检查项目 | 最低通过标准 | 结果 |
| --- | --- | --- | --- |
| 1 | 注册 | 可创建新账号；重复账号和无效输入有明确提示 | ☐ |
| 2 | 登录 / 退出 | 正确密码可登录；错误密码被拒绝；退出后受限接口不可访问 | ☐ |
| 3 | 我的族谱 | 可打开列表，显示已加入族谱、角色和加入码 | ☐ |
| 4 | 切换凌氏家谱 / 张氏族谱 | 两本族谱可相互切换，名称和数据不串联 | ☐ |
| 5 | 树状族谱 | 人物、配偶和代际关系正常显示；缩放、拖动、适应视图可用 | ☐ |
| 6 | 新建空白族谱 | 创建后为空白，不生成示例人物；60 秒冷却正常 | ☐ |
| 7 | 添加人物 | 可添加首位人物及后续人物，写入当前 family_id | ☐ |
| 8 | 添加父母 / 子女 / 配偶 | 三类关系均可添加；树刷新；世代重算；重复和循环被拒绝 | ☐ |
| 9 | 人物详情 | 基础资料、父母、配偶、子女、生平和照片区域可打开 | ☐ |
| 10 | 认领本人 | 可提交认领；重复认领受限；管理员可看到待审核记录 | ☐ |
| 11 | 五代谱 | 上五代、下五代、上下五代均可生成并返回完整族谱 | ☐ |
| 12 | 关系与称谓 | 可选择人物 A/B；显示关系链、双向称谓和代差 | ☐ |
| 13 | 搜索 | 姓名、拼音首字母和代数搜索可用；错字/同音提示正常 | ☐ |
| 14 | PDF 导出 | 完整族谱和当前五代谱可导出；PDF 不含操作界面 | ☐ |
| 15 | 管理员权限 | OWNER/ADMIN 可管理；EDITOR 受创建人限制；VIEWER 只读 | ☐ |
